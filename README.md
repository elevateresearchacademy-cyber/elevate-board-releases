# Elevate Board: downloads

Installers for Elevate Board, a see-through annotation board for online classes by Elevate IELTS.
Windows 10 and 11, 64-bit. This repository holds downloads only; it contains no source code.

Get the latest version from the Releases page, or from https://elevateielts.com/tools

- Setup installs Elevate Board with a desktop shortcut. Portable runs without installing.
- Arabic files are the same app starting in Arabic; every copy can switch language from the toolbar.
- The installers are not code-signed yet. On first run Windows may show "Windows protected your PC": click More info, then Run anyway.
- SHA256SUMS.txt lists the checksum of each file.
